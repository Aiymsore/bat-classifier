# 方法说明

## 当前处理流程

1. 读取 WAV，并统一为 250 kHz 单声道信号。
2. 高通滤波，降低低频背景噪声。
3. 按能量阈值检测候选脉冲，并精修起止边界。
4. 在候选片段内追踪频谱峰，实验性拆分同时出现的近频声波。
5. 提取持续时间、峰值频率、起止频率、带宽、斜率、SNR、轨迹覆盖率等特征。
6. 使用质量规则生成原型级 `noise/bat` 标签，并训练随机森林门控模型。
7. 对通过门控的脉冲进行标准化、PCA 与 KMeans 聚类，得到 A–D 四类临时声型。
8. 训练临时分类器，使新录音可被自动映射到 A–D。

## 必须明确的边界

- A–D 是无监督聚类得到的临时声型，不是经过专家确认的物种标签。
- `noise/bat` 的训练标签来自当前质量筛选规则，不等同于独立人工标注的真实标签。
- 单通道录音中，完全同频且同时出现的声源通常无法可靠分离。
- 当前数据量较小，结果主要用于证明处理流程可运行，不能直接作为野外物种鉴定工具。

## 下一阶段

获得老师确认的物种数据库后，应按录音来源进行分组划分训练集和测试集，避免同一录音的脉冲同时进入训练与测试；随后报告宏平均 F1、混淆矩阵、每类召回率和外部测试集表现。
