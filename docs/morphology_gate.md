# CF / CF-FM / FM 门控（morphology-v6）

2026-11-13 更新：门控使用原混合谱中找回的完整轨迹 `_boundary_track`，与平台测量共享观测支持帧，重新计算覆盖率、轨迹时长和形态。保留原混合谱的集中度及熵约束；不能依靠分离掩膜使噪声通过。缺少完整观测轨迹时才退回 `_gate_track` 与强帧规则。断点处理版本升为15，旧结果需要重跑。

2026-11-09 更新：移除尾段能量比、尾段下移量参与的 CF-FM 尾段旁路，
只保留已观测轨迹形态评分。`gate_tail_score` 旧字段固定为 0，
`gate_cffm_source` 不再取 `tail`。尾段诊断值不参与模板匹配或连串判族。
下文涉及 v3 尾段旁路的说明仅为历史记录，不适用于当前版本。

实现位于 `src/bat_classifier/morphology_gate.py`，接入点是 `pulse_table.create_pulse_rows`。分离后每个独立分量评一次，谐波随声源成组，最低可见轨迹不直接认作真实基频。该版本是可解释的规则版，阈值由下面说明的运行数据标定，**尚未由独立人工标注集校准**；分数不是准确率或概率。

## 数据流与复用

候选声波 → 独立分量和谐波组 → 共用频谱及已观测轨迹 → 三类评分和背景证据 → bat / noise / uncertain → bat 与 uncertain 匹配模板。

同一分量仅用一次特征 STFT，建表、模板与门控分别处理它。门控优先使用分离时已有连续轨迹，缺少时使用共用谱主频；两条轨迹之间的跳频不会通过补基频消除。分离同时传递分离前功率谱的轨迹能量占比和熵，避免掩膜人为提高噪声的集中度。

存在完整观测轨迹时，取该轨迹在真实音频中的支持帧；没有该轨迹时才取相对峰值不低于 -24dB 的帧。形态轨迹做三点中值平滑，连续性仍检查未平滑频率及时间缺帧。覆盖率在同一套观测支持帧上计算，并保留原轨迹内部缺帧比例约束。

所有指标缩放到 0～1。`ramp(x,a,b)=clip((x-a)/(b-a),0,1)`。频率容差 `T=max(1kHz,2×频率格点间隔)`；250kHz、512点 FFT 时 T=1kHz，短脉冲采用较小 FFT 时相应放宽。

## 共用指标

- 瞬时集中度 C：每帧轨迹附近 ±max(1.5kHz,2格点) 的能量占**整段 15–120kHz 超声带**能量的比例，再求均值。可信谐波组可合并所属谐波带。取分量频谱与分离前原谱支持度中较小值，评分 `C'=ramp(C,0.15,0.65)`。FM 的总带宽不会作为弥散噪声带宽。
- 局部带集中度 C_loc：同一分子，分母换成轨迹周围 ±max(6kHz,4×半径) 的局部带能量。平谱噪声的理论基线约为 近场带宽/局部带宽 ≈ 3/12 ≈ 0.25，因此它回答的是"轨迹处是否真有窄带峰"，不会被整段频带的噪声总量稀释。C_loc 不参与形态分，只用于下面两条旁路。
- 连续性 L：相邻原始轨迹跳变不超过 max(3kHz,12kHz/ms×时间差)，且时间差不超过 2.1 个 hop 的比例。有分离轨迹时再乘它的实际帧覆盖率。
- 覆盖率 V：有效轨迹帧 / 活动谱帧，再乘分离轨迹自身覆盖率。
- 时长得分 D：`ramp(轨迹时长ms,0.25,0.8) × (1-ramp(时长,80,150))`。该范围仅供门控，前面的候选检测仍有自己的时长范围。
- 质量 Q：`0.30L + 0.30C' + 0.20V + 0.20D`（仍用全带 C'，保持与旧版可比）。
- 归一化频谱熵 H：越接近 1，表示同一帧的能量越宽频分散；取分离前后较大值。

## 三类形态分数

### CF

`CF = 0.30P + 0.25S + 0.20C' + 0.15L + 0.10D`

- P：频率极差不超过 T 的最长连续平台时长 / 全轨迹时长。
- S：`1-ramp(轨迹95分位-5分位频率,T,3T)`，衡量整条轨迹频率稳定性。
- C'、L、D 分别反映能量集中、连续性、持续时间。

轻微漂移的 QCF 可获得部分平台分，不会只因非完全水平而拒绝。

### FM

`FM = E × (0.30E + 0.25M + 0.20R + 0.15C' + 0.10D)`

- E：首尾各两点的频率中位数差的绝对值，经过 `ramp(差值,max(1.5,2T),max(6,6T))` 缩放，单位 kHz。
- M：首尾频率差 / 累计逐步频率变化量，衡量扫频单向性；允许连续上扫、下扫和弯曲轨迹。
- R：二阶频率差的90分位经过 `1-ramp(值,T,4T)`，衡量局部平顺程度。
- 外乘 E：使完全水平线不能仅靠连续、平滑取得高 FM 分。

### CF-FM

搜索 CF→FM、FM→CF，以及最长平台两侧的组合；最多取24个候选切点，保留原有时间顺序。

`CF-FM = max[ min(Pc,Fm) × (0.25Pc + 0.25Fm + 0.25J + 0.15C' + 0.10L) ]`

- Pc：平台平坦度 × 平台持续时间支持 × 平台占全轨迹比例支持。平台超过 T 后逐渐减分，到2T为0；持续0.3～0.8ms由0升至1，占比10%～30%由0升至1。
- Fm：该扫频段的 `E×(0.6M+0.4R)`，再乘持续0.2～0.5ms的支持度。
- J：检查两段连接附近原始轨迹的跳变，T以内为1，4T以上为0。两段必须相邻，共享真实观测连接点。
- 外乘 min(Pc,Fm)：缺平台或缺扫频段时不能靠另一段独自拿高分。

**尾段路径（v3 新增）**：实测 CF-FM 的尾巴常与 CF 主线并存且更弱，逐帧最强频率一直停在 CF 上，上面的轨迹路径测不到扫频段。尾段路径改看共用频谱的尾段能量分布（与模板特征 `tail_low_energy_ratio`、`tail_drop_khz` 同一算法）：

`CF-FM_tail = min(Pt, Ft) × (0.25Pt + 0.25Ft + 0.25×1 + 0.15C' + 0.10L)`

- Ft（`gate_tail_score`）：`ramp(尾段低频能量占比,0.10,0.30) × (0.5 + 0.5×ramp(尾段低频边缘下移kHz,1,3))`。2025 罗汉洞模板中 CF 占比 ≤0.06，CF-FM 为 0.13–0.91。
- Pt：`ramp(最长平台ms,0.3,0.8) × ramp(平台占比,0.10,0.30) × ramp(横频平台ms,3,5)`。最后一项要求有实在的横频平台（CF-FM 模板平台 ≥5 ms），宽带瞬态里偶然的平坦段不算。
- 尾巴与主线并存，没有接点跳频可检验，接点项按 1 计。

CF-FM 分取轨迹路径与尾段路径的较大值，`gate_cffm_source` 记录来源（`track`/`tail`）。

尾段证据只用于形态标签和 bat 判定，**不参与噪声规则**：`diffuse_broadband` 与 `broadband_impulse` 中的“最高形态分”仍取不含尾段路径的轨迹形态分。宽带能量天然有一部分落在“主频”下方，若让尾段证据参与，实测会把约 1,500 条宽带瞬态从 noise 拉回待定。加上这两条约束后，20 个录音（7,677 个分量）上 noise 不变，uncertain→bat 11 条、bat→uncertain 1 条，CF-FM 形态标签由 89 增至 153。

**短平台条件（v3 新增）**：与分类判族一致（专家确认 CF 的横频时间更长），CF-FM 通道整体乘以 `1 - ramp(横频平台ms, 阈值-2, 阈值+2)`，平台为模板特征 `cf_plateau_ms`，阈值为 `config.TEMPLATE_CF_MIN_PLATEAU_MS`（当前 17 ms，即 ramp(15,19)）。带首尾 FM 的长 CF 叫声（如 47 kHz FM-CF-FM）在门控里归 CF 形态，不再标为 CF-FM。门控固定使用配置默认值，界面上调整“CF 最短平台”只影响分类判族。

三个分数均记录。通常选择最高分形态；CF-FM≥0.65且距最高分不超过0.08时优先显示 CF-FM，减少长平台掩盖短尾部的情况。形态标签只表示最支持的通道，即使最终是 noise/uncertain 也会保留，便于调试。

## 综合判定

综合分 `G=clip(0.8×三类最高分 + 0.2Q + 谐波加分 + 背景加分 - 持续音惩罚,0,1)`。

- 谐波加分：0～0.05，根据现有可信倍频覆盖率与包络相关性给分；没有谐波加分为0。
- 背景加分：前后各4ms原音频，与同一原混合候选区间比较 RMS，突出3～12dB给0～0.04分。文件边缘缺少任一侧背景时不加分，不判持续干扰。
- 持续音证据：同频正弦投影在前后背景均达到候选内部70%以上，候选内0.25ms RMS 包络变异系数<0.15，且同频投影幅度显著。稳定性≥0.8时减0.35分。

**必需条件（五项，全部满足才可能判 bat）**

| 条件 | 阈值 |
|---|---|
| 综合分 G | ≥0.72 |
| 质量 Q | ≥0.55 |
| 轨迹覆盖率 V | ≥0.55 |
| 连续性 L | ≥0.65 |
| 轨迹时长 | ≥0.5ms |

**能量证据（两条并列路径，任一满足即可）**

- `band`：全带集中度 C ≥0.25；
- `rescue`：C <0.25，但 C_loc ≥0.90 且最高形态分 ≥0.80——"整段频带有噪声，但轨迹周围仍是干净窄带峰"的真叫声按局部带救回。

按以下优先级判定：

1. 持续音证据成立、S≥0.8且P≥0.85：noise，原因 `persistent_tone`。
2. C<0.18、H>0.80、三类最高分<0.60且无可信谐波支持：noise，原因 `diffuse_broadband`。
3. C<0.25、C_loc<0.40、最高形态分<0.70、H>0.45 且无可信谐波支持：noise，原因 `broadband_impulse`。该规则只在全带集中度已不达标的候选中生效，因此不会影响走 `band` 路径的判定。
4. 必需条件全满足且能量证据成立：bat，原因 `supported_shape`，`gate_pass_path` 记录 `band` 或 `rescue`。
5. 其他或材料不足：uncertain，`gate_reason` 列出每一项未达标值，`gate_fail_*` 给出对应布尔列。不会仅凭低模板相似度判 noise。

## 模板放行（V1.5，默认关闭）

门控只缺能量证据时，模板相似度可以补上这块证据。开关 `allow_template_promotion` 默认关闭；开启后，一条 uncertain 行必须同时满足下面全部条件才改为 bat：

- 失败项只允许是 **全带集中度、局部带集中度、综合分**；
- **覆盖率、连续性、轨迹时长、质量** 四项必须全部通过（信号完整性证据不接受模板代偿）；
- 模板相似度 ≥ 页面上的"最低相似度"（默认 0.60），且类别不是 `unknown`；
- **门控形态与模板类别一致**（`CF*`↔CF、`CFFM*`↔CF-FM、`FM*`↔FM）。

放行行写入 `gate_status="bat"`、`gate_pass_path="template"`、`gate_promoted=True`、原因码 `template_promoted`，**原始未达标项保留在 `gate_fail_*` 里**，方便事后按标记剔除重算。统计中单列 `template_promoted_count`。

实测（20261022_123148，13,676 个分量，阈值 0.60）：放行 1,022 行中约 884 行通过形态一致性守卫，约占现有 uncertain 的 20%。放行行模板分中位 0.72、熵 0.50、C_loc 0.71、覆盖率 0.95；作为对照，bat 群体是 0.81 / 0.40 / 0.97 / 1.00，noise 群体是 0.63 熵。

风险（已记录，不随开关自动消失）：

- 放行使用模板相似度，而相似度只表示"在模板库里最像哪一条"，不是"是不是蝙蝠"。模板库越大越杂，偶然相似的概率越高。
- 有效叫声数从此依赖模板库：换模板、加模板会改变总数，不只是改变类别。开关状态写入 `run_metadata.json` 与断点校验，混用会被拒绝续跑。
- 稀有类别会被放大（本例 `CF6_108K` 由 3 条增至 50 条量级），需要人工抽查。
- 约 13% 的候选因形态与模板类别不一致被守卫挡下，其中多为"纯 CF 片段被归到 CFFM 模板"。它们不会被放行，但仍会作为 uncertain 保留。

## 噪声如何判定，为什么剩余的待定没有判 noise

三条噪声规则都要求**同时**出现多种"非生物来源"的正面证据，而不是"证据不足"：

| 规则 | 条件 | 本例条数 |
|---|---|---|
| `persistent_tone` | 同频正弦投影在前后背景都达到候选内部 70% 以上，且包络近似恒定（变异系数 <0.15） | 137 |
| `diffuse_broadband` | 全带集中度 <0.18、熵 >0.80、最高形态分 <0.60、无谐波支持 | 30 |
| `broadband_impulse` | 全带集中度 <0.25、局部带 <0.40、最高形态分 <0.70、熵 >0.45、无谐波支持 | 948 |

剩下的 uncertain 之所以不判 noise，是因为它们各自还保留至少一条"像叫声"的证据（同一批 4,450 行）：

- 2,737 行（61.5%）有明确的 CF/FM 形态（最高形态分 ≥0.70）——`broadband_impulse` 的形状护栏正是为了不把"噪声带里的真叫声"吃掉；
- 926 行局部带也没有峰，但其中 698 行形态分 ≥0.70、144 行熵 ≤0.45，不满足"宽带弥散"或"无形态"的条件；
- 2,708 行处在救回区（C_loc 0.40–0.90、全带 <0.25）；
- 980 行全带集中度已经达标，缺的是综合分/覆盖率等其它证据。

这里的原则是**误判方向不对称**：判成 noise 的声波会从计数中消失、不再出图、也不会进入复核；判成 uncertain 只是多花人工。所以只有能"正面证明是非生物来源"时才判 noise，其余一律留给复核。模板放行打开后，uncertain 会进一步下降，但 noise 集合不变。


## 标定与实测（运行 20261020_125835）

同一批 180 条录音、13,701 个分量，用新旧两版门控各跑一遍（除门控外参数与检测/分离完全相同）：

| 状态 | 旧 v1 | 新 v2 | 变化 |
|---|---|---|---|
| bat | 7,778 | 8,117 | +339 |
| uncertain | 5,756（42.0%） | 4,460（32.6%） | −1,296（−22.5%） |
| noise | 167 | 1,124 | +957 |

- 救回的 339 行：模板相似度中位 0.817、≥0.6 占比 73.7%，与旧 bat 群体（0.813 / 73.3%）统计上无法区分，因此判断它们是真叫声被全带噪声稀释掉的那部分。
- 转入 noise 的 957 行：模板相似度中位 0.215、≥0.6 仅 9.7%、最高形态分中位 0.47，而保留下来的 uncertain 为 0.346 / 23.8%，属宽带瞬态。
- 原 bat 被判为 noise：0 行；走 `band` 路径的 bat 数量与旧版完全相同（7,778），说明新规则没有改动原有通过人群。
- 每个文件的中位待复核数：13 → 10。
- 用局部带集中度**替换**全带阈值并不可行：以旧判定为标签时，全带集中度 AUC=0.984、局部带仅 0.913；若把 bat 门槛直接换成 C_loc≥0.55，会丢掉约 6.6% 的现有 bat。所以局部带只作旁路。
- 标定使用的弱监督是模板相似度，不是人工标注；换录音或换模板库后阈值需要重新核对。

## 输出与调试

`gate_status`、`gate_shape`、`gate_score`、三类 `gate_*_score`、`gate_quality`、`gate_concentration`（全带）、`gate_concentration_local`（局部带）、`gate_local_band_hz`、`gate_entropy`、`gate_coverage`、`gate_continuity`、`gate_track_duration_ms`、`gate_context_contrast_db`、`gate_harmonic_support`、`gate_pass_path`、`gate_promoted`、`gate_reason`、`gate_reason_code`、`gate_fail_checks` 与 `gate_fail_*` 布尔列进入逐声波 CSV。`gate_fail_*` 只在非 bat 行描述"为什么没判 bat"；bat 行一般为 False，唯一例外是 `gate_promoted=True` 的放行行——它们保留触发放行的原始未达标项。模板辅助结果在 `template_predicted_label`、`template_match_score`、`template_file` 中独立保留。uncertain 的最终 `predicted_label` 仍是 uncertain，模板高分不自动把它提升为 bat。

逐声波图片标题包含门控状态/形态、三类分数、`C_loc`、原因码，以及模板辅助类别和相似度分数（`template=CF1_47K (0.73)`）。

图片按类别分三组开关：**常规图片**（已分类的 bat）、**unknown**（门控 bat 但模板未匹配，默认关闭）、**uncertain**（门控待定，默认关闭）。unknown 单独成组后，常规图片不再混入未匹配样本；三者互不影响计数。

只有 bat 进入各类别计数及有效叫声速率；noise 与 `gate_uncertain_count` 单列。bat 中的类别 unknown 存入 `template_unknown_count`，兼容字段 `uncertain_count` 保持同义。

调试图开关独立于常规图片，默认关闭。开启后输出 `pulse_spectrograms/uncertain/`。合并模式按同事件、同门控状态分组；分开模式使用相应分量音频，谐波不另成图。关闭调试图不会删除旧任务已有的图片。

## 当前限制

- 阈值仍缺人工标注集校准；报出的"救回/噪声化"数字是与模板相似度对照的结果，不是准确率。
- 很弱、截断或跟踪不完整的 FM 尾部仍可能保留为 uncertain；门控位于候选检测之后，不能找回前面未检测到的叫声。
- 局部带集中度的平谱基线依赖局部带宽度（当前 6kHz 下界）。若以后调整近场半径或局部带宽，`ramp` 区间与 `rescue` / `broadband_impulse` 阈值需要一起重标。
