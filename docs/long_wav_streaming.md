# 模块①长录音流式处理

长录音以连续 chunk 覆盖整个输入文件，并在每块两侧保留重叠上下文。脉冲时间统一转为原录音的绝对时间，跨块重叠脉冲去重后进行模板匹配与统计。

- 默认每块 10 秒，两侧上下文由重叠参数控制。
- 分析采样率统一到 250 kHz，预处理包含去直流、高通和归一化。
- 静音快筛只减少计算，被跳过的时长仍进入监测时长统计。
- 有限并行处理块，按原录音顺序汇总；输出 WAV 的数量上限不影响检测与计数。
- 分量分离保留所属谐波；模板匹配每条声波产生一个类别或 unknown。
- 明细增量落盘，后台 stop() 请求在处理边界停止。
- checkpoint 保存处理位置、参数和累计统计；恢复时检查文件身份与处理参数。

整条录音正常结束后，还会读取完整特征记录，局部回读原音频检查边界可靠性，
再完成跨块连串复核、CF 准入和最终重计数。中途显示的单条结果可能与最终结果不同。
音频按块读取，但最终复核和批次汇总的内存随特征记录数增长；不能将整个程序
描述为内存与录音长度完全无关。主流程和输出文件见 [README](../README.md)。

## 漏检排查

某个文件"一个候选都没有"通常是检测层的问题，不是门控。开启「输出检测诊断 CSV」（默认关闭）后，`detection_diagnostics.csv` 会逐块记录全带与各子带的背景、对比度、阈值和候选数；`contrast_db` 低于 10 dB 的频带在该块内不可能产生候选。列说明与实例见 [检测诊断说明](detection_diagnostics.md)。

核心实现为 `segment_stream.py` 与 `segment_analysis.py`，使用方式见项目 README。
