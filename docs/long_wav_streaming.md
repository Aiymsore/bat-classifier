# 模块①长录音流式处理

长录音以连续 chunk 覆盖整个输入文件，并在每块两侧保留重叠上下文。脉冲时间统一转为原录音的绝对时间，跨块重叠脉冲去重后进行模板匹配与统计。

- 默认每块 10 秒，两侧上下文由重叠参数控制。
- 预处理使用 250 kHz 单声道、去直流、高通和归一化。
- 静音快筛只减少计算，被跳过的时长仍进入监测时长统计。
- 有限并行处理块，按原录音顺序汇总；输出 WAV 的数量上限不影响检测与计数。
- 分量分离保留所属谐波；模板匹配每条声波产生一个类别或 unknown。
- 明细增量落盘，后台 stop() 请求在处理边界停止。
- checkpoint 保存处理位置、参数和累计统计；恢复时检查文件身份与处理参数。

核心实现为 `segment_stream.py` 与 `segment_analysis.py`，使用方式见项目 README。
