# 连串判族（默认启用）与历史离线实验

## 当前正式行为（2026-11-26 核对）

完整录音处理结束时默认执行连串判族，无需 GUI 开关。跨分析块连接同频同类别
的门控 bat 叫声：相邻起点间隔不超过 200 ms、频率距串中位数不超过 1 kHz，
至少 3 条，且至少需要 2 条可靠参考成员。参考成员须有完整边界、足够的信噪比、
质量与覆盖率，且没有分割复核问题。使用可靠参考成员的平台时长中位数与 CF
平台阈值（默认 17 ms）比较；全部成员的实测中位数另行保留。
可靠参考不足、参考判族冲突、混群、连接歧义和同频重叠会记录复核原因，
不强制按全部短片段的中位数改类。
连串判族建议仍只改 CF 与 CF-FM 均达标的分量。所有最终 CF 另有统一准入检查，
不再因只有 CF 一族达标而绕过时长要求：单条平台达到阈值，或至少 3 条、
含至少 2 条可靠参考、无复核问题、参考平台时长中位数达到阈值的同类连串，才允许确认 CF。
因此 CF 单族的短分量也可获得合格长平台连串支持；其余短 CF 分量转待定，
不自动改成 CF-FM。原有 uncertain、noise、unknown 不会被该检查放行。

完整结束时还会局部回读原 WAV，检查边界完整性及同频相邻片段之间的桥接证据。
无法确定是否属于同一次叫声的片段标为 `segmentation_review`，最终转待定，
不计入确认叫声。检查不凭空补信号，也不改写实测起止时间。

尾段能量占比和下移量不再参与模板相似度、判族、连串或形态门控。
逐声波尾段特征保留作诊断；旧快照的尾段列和尾段门槛也被忽略。

`predicted_label` 和 `confidence` 是最终结果；`single_predicted_label` 和
`single_confidence` 保留原单条结果。模板辅助列仍描述单条模板判断，
连串依据在 `sequence_*` 和 `family_source`。每个片段另存 `sequence_summary.csv`。
类别统计、片段概览及发生改类的逐声波图片同步更新。

`cf_duration_source` 为 `single`、`sequence`、`review` 或 `not_cf`，
`cf_duration_accepted`/`cf_duration_review` 记录准入结果。
`single_gate_*` 和 `single_is_uncertain` 保留检查前的门控与放行记录；
短 CF 转待定后同步更新有效叫声数、待定数及分类图片，原候选数不变。

取消时保留单条中间结果供续跑，完整结束后再完成连串判族与CF准入。当前处理版本 15、
门控 morphology-v6；以源码和运行快照为准，不兼容的旧断点不能混用。新运行生效，旧结果不自动重写。
音频仍按块处理；最终连串需要读取该录音的完整特征记录，额外内存随声波数增加。

## 以下为历史离线实验记录（2026-11-08）

入口：`labeling_kit/tools/compare_sequences.py`。算法：`src/bat_classifier/sequence_analysis.py`。
目前只在现有CSV上生成建议，不接入桌面分析流程。源结果、人工计数、模板、门控、音频和图片都不改。

## 七步实现

1. 连串：同录音、同CF候选类别，距串内平台频率中位数≤1kHz，距上一条起点≤200ms。
   时间重叠不强行连接，出现两个可能的前序串时标记连接歧义；不跨录音、不跨类别。
2. 上下文：所有有CF候选的bat叫声均可提供时长上下文，单族达标的行也可参与。
   只有CF区间命中、CF-FM模板分≥最低相似度的行可获改类建议。noise、uncertain、unknown不提升。
3. 每串计算平台时长中位数、尾巴占比、频率中位数（内部用于连接）及条数。
   按源运行参数读取平台阈值（这批为17ms）和最低相似度（0.6）。
   中位数≥阈值判CF；短于阈值分两版试验：多数有尾巴才CF-FM，或只按时长判CF-FM。
   尾巴证据阈值0.10只用于第一版的串内占比，并未恢复生产流程的逐条尾巴硬门槛。
4. 少于3条的串沿用单条判定。
5. 混群：至少6条，一维两组最小平方误差划分；每组至少3条且占比≥30%；
   两组中位数分别位于判族阈值两侧、差≥10ms、各组IQR≤6ms时标记复核。
   连串歧义、同频时间重叠同样复核；均保留单条判定，不自动拆串。
6. 输出原始列及single_predicted_label、sequence_id、sequence_size、
   sequence_plateau_median_ms、sequence_tail_fraction、sequence_family、
   sequence_review_reason、family_source、sequence_predicted_label、sequence_changed。
   sequence_family是串的建议；只有双族达标行采用建议，其余仍是单条结果。
   原confidence/template_file描述原判定，不解释为序列建议的置信度或模板文件。
7. 在完整录音上连串，然后按窗口中心时间切出W13/W14/W15/W16评价；
   另外输出逐WAV、逐类别的新旧计数及参考表计数。总bat数保持不变。

## 结果与限制

输入 `results/segment_analysis/20261103_201628`。它是20250807完整180个录音的现有结果。
输出在 `results/sequence_experiments/20261108_tail_final` 和
`results/sequence_experiments/20261108_duration_final`。每个目录含逐条结果、序列表、
逐WAV对照、窗口对照、规则与输入SHA256、中文报告。

“同频且连续”不能证明来自同一个体；混群检查也只是启发式提示。
W13/W14的人工结论只验证已知窗口，不能据此保证全天改类正确。
W15/W16原来的漏检维持原状，不应把数量未增加理解为召回得到改善。
参考Avisoft汇总表计数口径不同，不作为逐条真值；不以总数更接近它决定规则优劣。
用户已说明W07约有72kHz 16条、47kHz 10条，未改写用户原CSV；重叠难数窗口不作为确定真值。
