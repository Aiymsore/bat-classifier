# 离线互调关系修正实验

本模块仅处理已有逐声波预测，尚未接入界面、检测器或正式计数。
原始列保持不变；新增 `intermodulation_status`、`corrected_counted`，
后者表示是否计入实验修正后的有效叫声数。

对原始 bat 和 uncertain 分量枚举同时存在的三条轨迹，检查
`product = 2 * parent_a - parent_b`。来源必须是实际观测到的分量；
不反推缺失来源，不新增叫声，不放行 uncertain 来源。noise 不参与。

## 第一版条件

- 直接读取原始 WAV 的局部混合频谱，2048 点 Hann STFT，步长 64。
- 在各分量峰值频率 ±1250 Hz 内逐帧找峰；此范围不足以覆盖的扫频可能漏检。
- 来源共同时间覆盖产物至少 90%，至少 8 个共同帧，并持续至少一个 FFT 窗。
  250 kHz 采样时一个窗为 8.192 ms；更短的信号仅记录证据，不自动排除。
- 至少 90% 的共同帧符合频率公式，误差不超过 2 个 FFT 格点。
- 三条峰的局部峰值/背景中位数均至少 10 dB；背景使用距轨迹 2–4 kHz 的频点。
- 两条来源的共同帧中位频带功率各至少为产物的 1.15 倍。
- 产物的 dB 包络与 `2*parent_a_dB + parent_b_dB` 预测包络相关系数至少 0.92，
  两者标准差至少 2 dB。窗口包括产物前后各 12 ms，不做延迟对齐。
- 在来源共同区间外（排除半个 FFT 窗的边缘）若产物仍有显著独立活动，保留。
- 多组来源同时达标则复核；某条候选产物同时被用作其他候选的来源，则复核，
  不链式扩张或循环归因。

这些条件属于未独立标定的保守规则，不是互调概率。通过说明多项证据相容，
不能证明设备失真发生位置。未通过不等于证明是真实独立叫声。
高阶互调、弱来源、超过搜索范围的轨迹、重叠来源归属不清等情况可能漏检。

## 运行

在仓库根目录使用项目 Python：

```powershell
.venv/Scripts/python.exe labeling_kit/tools/audit_intermodulation.py --predictions results/0347_tail_harmonics_20261109/pulse_predictions.csv --wav-dir ../声波文件/2025罗汉洞/20250807 --output results/intermodulation_experiments/0347_20261109
.venv/Scripts/python.exe tests/test_intermodulation.py
```

输出保留原始数据的逐声波表、每组三条轨迹的证据及失败项、逐录音逐类别计数对比、
参数和源预测文件 SHA256。最终图和中文报告另外保存于同一实验目录。

## 0347 验证结果

原有效 161 声，实验修正后 158 声；CF1_47K 从 7 降为 4，其他类别不变。
4 个分量符合排除条件，其中 3 个原为 bat、1 个原为 uncertain，因此只减少 3 声。
4 组来源均为原来已计数的 bat，没有新增叫声。
加入“至少一个 FFT 窗的共同支持”条件之前，初步结果为 7 个分量、4 个有效计数；
最终把短信号仅作复核，恢复了其中一个有效计数。

尚没有人工确认的独立 47 kHz 留出集。测试覆盖合成原始 WAV、独立包络、
来源缺席、独立活动、频率巧合、歧义、来源冲突和待定来源不放行；
这些测试不能代替真实数据的误删率验证。
