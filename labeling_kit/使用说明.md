# 人工标注工具包

用途：在 20 个 2 秒窗口里按**单条叫声**数一遍，作为标准答案，逐条评估程序的漏检、多检、分错类和碎片。
窗口来自 `2025罗汉洞/20250807`，程序结果对照用的是 `results/segment_analysis/20261103_201628`。

## 文件
| 文件 / 文件夹 | 内容 |
|---|---|
| `计数规则.md` | 什么算一条叫声、清晰度、类别怎么判。**先读完并确认末尾的 3 个问题再开始** |
| `窗口清单.csv` | 20 个窗口：录音文件、起止时间、抽样依据 |
| `空白声谱图/` | 每个窗口一张图，分 4 行、每行 0.5 s；横轴是相对窗口起点的时间，每 10 ms 一条细线；右侧虚线是各类别的参考频率 |
| `程序结果对照图/` | 同样的图，叠加了程序判为 bat 的框（颜色=类别）。**标完对应窗口之后再看** |
| `音频片段/` | 每个窗口的原始音频（250 kHz），可以拖进本软件或 Avisoft 里放大查看 |
| `标注表.csv` | 待填的表，第一行是示例，填写前删除 |
| `tools/` | 生成工具包和评分的脚本（不用动） |

## 抽样方式
- 每个类别 2 个窗口：一个取自人工表里该类最多的录音（密集），一个取自该类数量居中的录音（中等）；窗口位置取该录音中程序检出该类最多的 2 秒。
- 另有 4 个随机窗口（W17–W20），程序在里面没有检出 bat，用来查程序漏掉的叫声。
- 20 个窗口来自 20 个不同录音。

## 怎么标
1. 打开 `空白声谱图/` 里的一张图（可以用本软件的“PNG 文件夹”查看并放大，或任意看图软件）。
2. 每看到一条叫声，在 `标注表.csv` 里加一行：窗口编号、开始和结束时间（读图上横轴，单位秒，读到 1 ms 左右即可）、平台频率、类别、清晰度、备注。
3. 一个窗口里叫声很多时，建议从上到下、从左到右按顺序标，标过的可以在图上做记号，避免重复或漏掉。
4. 图上看不清的地方，打开 `音频片段/` 里对应的 WAV 放大查看。
5. 一个窗口标完后，再打开 `程序结果对照图/` 里的同一张图核对；如果发现自己漏标，可以补上，但在备注里写“看对照图后补”，评估时会单独统计这部分。

不需要一次标完 20 个窗口；先标 3–5 个，我就可以先跑一次评估，看规则是否需要调整。

## 标完之后
把填好的 `标注表.csv` 保存好（保持 CSV 格式、UTF-8），告诉我即可。评分命令：

```
.venv/Scripts/python.exe labeling_kit/tools/score_labels.py results/segment_analysis/20261103_201628
```

结果写在 `评估结果/`：召回（程序找到了多少人工叫声）、精确率（程序的 bat 有多少是真的）、类别一致率和混淆表、碎片数，按类别和窗口分别列出。
程序以后改了，用新的结果目录再跑一次评分，就能直接比较改动前后。
