# 叫声计数规则（草稿，开始标注前请确认或修改）

目的：建立按**单条叫声**计数的标准答案，用来逐条评估程序的漏检、多检和分错类。
规则一旦开始使用就不要再改；如果中途发现必须改，记下改动时间，之前标过的窗口按新规则复查一遍。

## 1. 什么算一条叫声
| 情况 | 计数 | 说明 |
|---|---|---|
| 一条 CF 叫声，连同开头上扫和结尾下扫 | 1 | 首尾调频属于同一条叫声，不单独计 |
| CF 中间短暂变弱或掉线，但前后同一频率、没有调频 | 1 | 掉线不拆成两条 |
| 前一条以下扫结束，后一条以上扫开始，中间空隙再短 | 2 | 有调频交界就是两条叫声 |
| 两只蝙蝠的叫声在时间上重叠（不同频率，或同频但起止不同） | 各计 1 | |
| 谐波（基频的 2 倍、3 倍等，起止与基频同步） | 0 | 只计基频那一条 |
| 回声（与某条叫声同频、稍晚、明显更弱、形状相同） | 0 | 拿不准时按"勉强可见"记下，备注写"可能回声" |
| 竖直的宽带咔嗒声，以及咔嗒声里固定频率的亮点 | 0 | |
| 低频（约 35 kHz 以下）的连续底噪 | 0 | |
| 被窗口起点或终点截断的叫声 | 1 | 只要叫声的一部分在窗口内就记，备注写"截断" |

## 2. 清晰程度（每条都要标）
- **清楚**：在空白图上一眼能看到，形状完整。
- **勉强**：看得出是叫声，但很弱、很短或被遮挡，自己也不完全确定。

评估时会分别统计"只算清楚的"和"清楚加勉强"两种口径。

## 3. 类别
按平台（横频段）频率和形状判断，图上有各类别的参考频率虚线：

| 类别 | 平台频率（模板） | 形状 |
|---|---|---|
| CF1_47K | 约 46–47 kHz | 长 CF，可带首尾调频 |
| CF2_58K | 约 58.6–59.6 kHz | 长 CF |
| CF3_66K | 约 66 kHz | 长 CF |
| CFFM1_67K | 约 66.4–67.4 kHz | 短 CF + 明显下扫 |
| CF4_72K | 约 71–72 kHz | 长 CF |
| CF5_83K | 约 80–86 kHz | 长 CF |
| CFFM2_86K | 约 83–86 kHz | 短 CF + 明显下扫 |
| CF6_108K | 约 103.5–105 kHz | 长 CF |

- CF 与 CF-FM 频率重叠时，按形状判断：横频段短、结尾有明显下扫的记 CF-FM，横频段长的记 CF。
- 看不出类别、或不属于以上任何一类：类别填 `?`，仍然计数。

## 4. 记录什么
每条叫声一行，填在 `标注表.csv`：
- `窗口`：窗口编号，如 W01；
- `开始_s`、`结束_s`：相对窗口起点的时间（秒，图上横轴就是这个时间，读到毫秒即可）；
- `频率_kHz`：平台频率（没有平台的填主频）；
- `类别`：见上表，拿不准填 `?`；
- `清晰度`：清楚 / 勉强；
- `备注`：可选，例如"截断""可能回声""与 W01 第 3 条重叠"。

时间读到大约 1 ms 就够；评估时按时间重叠和频率相差 3 kHz 以内来配对，不要求精确对齐。
