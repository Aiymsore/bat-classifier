# 蝙蝠声波模板分析工具

面向生态录音分析的 Python / PySide6 桌面工具，支持长 WAV 分块处理、模板辅助识别、叫声统计及声谱交互复核。

当前分析入口为 **① 片段识别与叫声统计**，使用**形态门控 + 可信模板匹配 + 整段边界与连串复核**。旧分类模型模式及噪声模板初筛已移除，历史录音、模板和结果不会被自动删除。

> 统计单位是声学 **call（叫声）**，不是蝙蝠个体；模板相似度不是分类正确率或校准概率。

## 从录音输入到结果输出

先区分三个对象：一条 **WAV 录音**可以包含很多次叫声；一个 **候选区间 candidate** 是检测器找到的疑似声音；候选中可能有多个 **分量 component**，每个可建表分量生成一行分析记录。它们不是一一对应的关系。

### 工作流程

1. **输入录音与可信模板。** 选择单个 WAV 或 WAV 文件夹，以及人工确认类别的模板目录。模板文件名提供类别，例如 `CF1_47K3` 归入 `CF1_47K`。后台线程预先准备模板特征、类别容差及频率轨迹，供同一批次的文件和音频块复用；这不是训练深度学习模型。
2. **探测文件并预处理。** 读取采样率、帧数及总时长，通过流式扫描获得全局均值和幅值峰值。读取分析块时重采样至 250 kHz、去均值、15 kHz 高通滤波并归一化，不将整段长录音一次载入内存。
3. **按重叠时间块调度。** 连续覆盖整条录音，在每个负责区间两侧增加上下文；使用有限线程池执行，按时间顺序归并。明显没有超声事件的块可以快筛跳过，但不从有效监测时长中扣除。
4. **检测候选并精修边界。** 对块音频计算 STFT 功率谱，根据全带能量和背景阈值寻找候选；默认还在模板相关子频带独立检测。随后精修核心和边界、处理相邻碎片，按候选中心时间决定块归属。候选只是疑似事件，不直接等于确认叫声。
5. **分离分量并提取特征。** 沿声谱峰值连接频率轨迹；存在多个可靠、同时出现且非谐波的轨迹时尝试分离，否则保留原波形。为每个可建表分量提取时长、主频、带宽、频率变化、恒频平台和模板轨迹。建表特征和模板描述复用分量频谱中间结果；局部时间换算为录音绝对时间后，再执行跨候选及跨块去重。
6. **形态门控与单条匹配。** 结合 CF / CF-FM / FM 形态、连续性、能量集中度和背景证据，区分 `bat`、`noise`、`uncertain`。明确噪声跳过模板匹配；`bat` 和待定分量继续匹配模板，并保留单条类别、相似度、门控状态及原因。
7. **增量保存和中断恢复。** 每块处理后保存逐声波明细、进度及 checkpoint，更新界面中间统计。停止时保留已处理结果，续跑前校验文件身份、处理版本和相关配置；中断状态不当作完整录音的最终结果。
8. **整段边界与连串复核。** 整条录音正常结束后，读取完整特征记录，并局部回读原音频评估边界完整性和同频片段分割。结合可靠参考成员的连串平台时长，复核 CF / CF-FM；执行统一 CF 准入与分割检查。证据不足的记录转待定，同时保留单条结果、连串依据和最终结果。
9. **重计数并导出。** 根据最终类别和门控状态，重算叫声、类别、待定数及叫声速率，输出 CSV、模板快照和运行参数；按开关及上限保存 WAV、概览和逐声波图片。完整结束前显示的计数可能与最终复核结果不同。

音频块默认负责 **10 秒**，两侧各读取最多 **0.75 秒**上下文，默认使用 **2 个工作线程**。例如负责 `10–20 s` 的块读取 `9.25–20.75 s`，并将局部时间换算回整条录音的绝对时间。按中心时间归属和跨块去重减少边界重复；分块与重叠不代表经过验证的绝对不漏检保证。

### 一条分量如何得到类别

以下为**默认路径**；实验性的“仅缺能量证据时按模板放行”默认关闭，其限制见后文。

- **`noise`：**保留明细和原因，跳过模板匹配，不计入确认叫声。
- **`uncertain`：**继续匹配模板供人工复核，但默认保持待定，不计入确认叫声。
- **`bat` 且模板达标：**获得单条模板类别，后续仍需通过整段边界、连串和最终准入复核。
- **`bat` 但模板未达标：**记为 `unknown`，类别未知，仍计入通过门控的叫声；最终若发现分割歧义等问题，也可能转待定。

CF 主要按平台频率区间产生候选类别，其他族结合特征和频率轨迹匹配。整段复核可能改变单条类别与门控状态，最终统计以复核后的记录为准。

| 阶段 | 输入 → 输出 | 主要实现 |
| --- | --- | --- |
| 界面与后台任务 | WAV / 文件夹及模板 → 配置、模板快照、分析任务 | [界面](src/bat_classifier/app/segment_analysis_tab.py)、[后台线程](src/bat_classifier/app/workers.py) |

**具体例子：**假设 `12.340–12.350 s` 有一条 10 ms 事件，它由负责 `10–20 s` 的块处理。在 250 kHz 下，10 ms 对应约 2500 个采样点。检测和精修后，一个可靠分量通常生成一行明细；若分离出两个可靠的独立分量，则可能生成两行。门控通过但模板未达标时记为 `unknown`；最终待定时保留为 `uncertain`，不会因导出了图片就自动计入确认叫声。此例仅解释流程，不是一次实测结果。

### 结果与计数边界

- `noise`、`uncertain`、`unknown` 含义不同：默认有效叫声统计最终 `bat` 行，包含其中的 `unknown`。
- CF 区间命中可以记相似度 `1.0`，这表示规则命中，不表示正确率 100%。
- 中途显示的是单条中间结果；完整结束后才完成边界与连串复核、最终重计数。
- 关闭图片或达到 WAV 导出上限只影响导出，不截断分析计数。
- 音频按块读取，但最终复核及批次汇总会读取特征记录，内存仍随事件数增长，不能说整个程序内存与录音长度完全无关。

## 结果文件

每次分析写入独立的 `results/segment_analysis/<run_id>/`：

| 输出 | 用途 |
| --- | --- |
| `pulse_predictions.csv` | 逐分量特征、门控、模板、单条和最终类别、音频与图片路径 |
| `segment_summary.csv` | 每条输入录音的叫声、类别、待定数和叫声速率 |
| `overall_species_summary.csv` | 按模板类别汇总；文件名不表示个体数或物种鉴定准确率 |
| `segments/<录音>/pulse_results.csv` | 每条录音的完整逐声波明细 |
| `segments/<录音>/sequence_summary.csv` | 连串成员、可靠参考、判族结果及复核原因 |
| `template_model.json`、`run_metadata.json` | 本次使用的模板快照、参数和处理版本 |
| `detection_diagnostics.csv` | 可选的检测诊断，默认关闭 |
| `segments/`、`separated/`、`figures/`、`pulse_spectrograms/` | 按开关和导出上限保存的音频、概览及逐声波图 |

详细字段和使用选项见后文。仓库不提交本机生成的批次录音、图像、模型及实验输出。

## 启动

Windows 双击 `run_app.bat`。首次配置环境：

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe bat_classifier_app.py
```

`run.py` 和 `python -m bat_classifier`（需设置 `PYTHONPATH=src`）也启动桌面界面。
窗口大小、位置和日志显示状态保存在工作区 `app_settings.json`；可读取旧版设置，旧训练设置不再使用。

## ① 片段识别与叫声统计

1. 选择模板 WAV 文件夹，文件名决定可信类别。
2. 选择待分析的 WAV 或 WAV 文件夹。
3. 设置最低相似度、分离窗、谐波处理；选择常规 / unknown / uncertain 三组图片开关、图片输出方式，以及是否允许"仅缺能量证据时按模板相似度放行"和是否输出检测诊断 CSV，开始分析。

每个候选分量先进行 CF / CF-FM / FM 形态门控。`bat` 进入全部模板匹配；`noise` 保留明细和原因，不进入模板匹配及叫声统计；`uncertain` 保留 WAV 和明细，继续匹配模板辅助复核，但不计入确定的蝙蝠叫声。通过 bat 门控后，模板相似度不足的类别为 `unknown`，仍计入蝙蝠叫声。
相似度不是分类正确率或校准概率。所有同类模板都保留，不做聚类或去重。

模板按文件名前缀分族（`CF*` → CF，`CFFM*` → CF-FM，`FM*` → FM，其余 other），各族用自己的特征打分：
- **CF 族按频率区间识别**：每个 CF 类别取其模板平台主频（`cf_plateau_khz`）的 [最低 − 2, 最高 + 2] kHz 为区间，实测叫声平台主频落入区间即判为该类，相似度记 1.0；多个区间都包含时取离最近模板频率最近的类。不用频率轨迹，不看首尾 FM，因此只保留横频段的 CF 模板可以匹配带首尾调频的实测 CF 叫声，模板频率跨度较宽的类别（如 CF5_83K）也按一个类别统计。平台（主频保持在 ±1 kHz 内的最长连续段，`cf_plateau_ms`）短于 2 ms 的声波不参与 CF 区间识别。余量与最短平台见 `config.py` 的 `TEMPLATE_CF_*`。
- **CF-FM 及其他族**使用常规频率、时长等特征及频率轨迹；尾段能量占比和尾段下移量不参与模板比较。

各族先取最佳模板；只有一个族达标时先采用单条结果。CF 与 CF-FM 同时达标时，先按单条横频平台时长判族（默认 17 ms），再执行完整录音的连串复核。连接同 CF 候选类别、起点间隔不超过 200 ms、平台频率距串中位数不超过 1 kHz 的 bat 叫声；默认至少 3 条组成序列，并需至少 2 条可靠参考成员。可靠参考要求边界完整、质量和覆盖率达标、没有分割复核问题；判族使用**可靠参考成员**的平台时长中位数，全部成员的实测中位数另行保留。可靠参考不足、参考判族冲突、混群、连接歧义或同频重叠会保留复核原因，不强制按全串中位数改类。双族达标行可获得连串改类建议，单族行提供上下文；随后仍须执行最终 CF 准入与分割检查。

所有最终 CF 均需满足统一准入：单条平台达到阈值（默认 17 ms），或获得至少 3 条且至少含 2 条可靠参考成员、无复核问题、参考平台时长中位数达到阈值的同类连串支持。只有 CF 模板达标也不能绕过该检查；短平台缺少合格连串时转待定，不自动归 CF-FM。原音频还会用于判断同频相邻片段是否存在连续桥接证据；分割仍有歧义的记录转 `uncertain`，不计入确认叫声。`cf_duration_source`、`cf_duration_accepted`、`cf_duration_review` 记录准入原因，`boundary_*`、`segmentation_review*` 记录边界与分割证据，`single_gate_*` 保留原门控。该检查不凭空补齐波形或修改实测起止时间。

连串可跨 10 秒分析块。最终逐声波表、片段/类别计数及改类图片使用连串结果；`single_predicted_label`、`single_confidence` 保留单条结果，`sequence_*` 和 `family_source` 记录依据，每片段另有 `sequence_summary.csv`。`template_*` 仍描述单条模板辅助判断。完整结束前显示的是单条中间结果，停止后可续跑。

尾段特征仅留在逐声波明细作诊断，不再影响门控、模板得分或连串判族；旧模板快照中的尾段特征和门槛也被忽略。处理版本更新后旧断点需要重新开始，已有结果不会自动改变。详见 [连串判族说明](docs/sequence_experiment.md)。音频仍分块处理，最终连串会读取完整特征记录，额外内存随该录音的声波数量增长。

分析音频统一到 250 kHz，去直流、15 kHz 高通和归一化后，进行检测、边界精修、分量分离与特征提取。
边界精修先用严格阈值定位核心，再在较宽上下文（至少前后各 100 ms，并覆盖最大叫声时长）中估计每个频点的固定背景。从核心向两侧追踪连续局部谱峰：要求高于固定背景及邻频背景各 6 dB，可跨过不超过 0.5 ms 的短缺口；遇到持续缺口或达到最大时长就停止，不反复用短平台自身重估背景。相邻频率搜索限制防止跳到无关声源。随后按原规则去重、合并同频碎片；有明确间隙或首尾扫频证据的相邻叫声保持分开。

分离阶段在精修候选内核查实际存在的弱谱峰，扩展分量轨迹后再截取，避免只保留中间强段。平台时长、建表和模板轨迹复用这些实际观测帧；核心质量评估仍独立保留。明细新增 `core_start_s/core_end_s`、`boundary_start_s/boundary_end_s`、`boundary_method`，与最终分量 `start_s/end_s` 分开记录，合并候选中的核心字段为各核心的首尾包络。背景不足或信号太弱时仍可能早停；精修候选范围不等于人工真值，不会固定补满时间或自动放行。默认分块重叠为 0.75 秒，最小重叠按最大时长与背景上下文校验。当前处理版本为 `15`，门控版本为 `morphology-v6`；以源码及运行快照为准，不兼容的旧断点需要重跑。

门控使用连续轨迹的三类形态、全带与局部带两级能量集中度、前后背景与可信谐波证据，规则和阈值见 [形态门控评分说明](docs/morphology_gate.md)。`noise pulse` 仍是兼容的模板类别名，与门控 `noise` 不等同。形态分数是规则支持度，不是校准概率；现有三类规则保留 QCF 等过渡形态及缺少证据的声波用于复核。
全带集中度不足、但轨迹周围仍是干净窄带峰的分量会按局部带救回为 bat（`gate_pass_path=rescue`）；全带与局部带都没有窄带峰、形态证据弱的宽带瞬态判为 noise（`broadband_impulse`），不再占用人工复核。
“仅缺能量证据时按模板相似度放行（实验）”默认关闭。开启后，门控待定、且只缺全带/局部带集中度或综合分（覆盖率、连续性、时长、质量必须全部通过）的行，若模板相似度达到“最低相似度”且门控形态与模板类别一致，则计入有效叫声，标记 `gate_pass_path=template`、`gate_promoted=True`，原始未达标项仍保留在 `gate_fail_*`。这会让叫声总数依赖模板库，`run_metadata.json` 和断点校验都会记录该开关。

分析导出 bat / uncertain WAV 和全部门控明细、统计表。逐声波图片按三组开关独立控制：**常规图片**（片段概览和已分类的 bat）、**unknown 频谱图**（门控 bat 但模板未匹配，默认关闭，`pulse_spectrograms/unknown/`）、**uncertain 频谱图**（门控待定，默认关闭，供调试）。unknown 独立成组后不再混进常规图片。三组都关闭时跳过全部逐声波图片，不构建绘图音频缓存。开关只影响图片，门控分数、WAV 和计数不变。直接打开 WAV/SON 和已有图片的查看功能仍可使用。
声谱图可选“合并显示”或“分开显示”。分开显示使用分离音频；谐波随所属叫声保留在同一张图，不单独计数。
直接查看 WAV、分析概览和逐声波输出共用一套绘图：上方为橙色正负振幅波形（幅度峰值归一化），下方为深蓝→蓝→青→绿→黄的彩色声谱，颜色越接近黄色表示相对能量越强。短 WAV 与逐声波图共用 STFT 参数和显示尺度；长录音的概览保留有界的频谱摘要及真实波形峰谷，不加载整条录音用于分析。默认 pulse 上下文为 0 ms，逐声波标题保留时长、频率、门控三类分数、局部带集中度、原因码，以及模板辅助类别与相似度分数（例如 `template=CF1_47K (0.73)`），`unknown` 与 `uncertain` 都能直接看出差多少。可放大、拖动、适应窗口查看。没有同名 WAV 的 SON 文件，上方标为“频谱幅度包络”。旧 PNG 需要重新生成才能更新显示。
声谱显示增益以可见频段的 99.9 分位 dB 值为参考峰值，显示其下 60 dB 范围，最上方约 0.1% 的点饱和为最高色，避免个别冲击尖峰压暗整图。颜色只表示当前图内的相对强弱，不用于噪声判定或跨图绝对能量比较；静音显示为深底色。
“直接打开 WAV/SON 查看”支持独立查看录音和 Avisoft SON 声谱文件。显示的频率范围默认自动覆盖所有有叫声的频段：每个频率比较时间上的 97 分位与中位数，高出 10 dB 以上（叫声来来去去）才算有叫声，连续的低频底噪和偶发的咔嗒声不会把范围带偏；找不到时（如只含一条叫声的短片段）退回只看最强频带。数叫声时可勾选“直接查看时显示完整频段（15–120 kHz）”，整段录音里偶尔出现一两次的种类也不会被裁掉。
也可将 WAV/SON 文件直接拖入主窗口，打开同一查看交互，无需先选择模板或运行分析。
将包含 PNG 的文件夹拖入主窗口，可递归浏览其中的声谱图和线性图，也支持单个 PNG。
图片附有同名频率坐标 JSON 时启用鼠标频率光标；缺少或无效时显示原图，仍支持缩放与拖动。
关联 WAV 的声谱图支持局部重新计算：在声谱区按住 Shift 拖选不超过 2 秒的时间段，再点“重算选区”；Ctrl+滚轮围绕鼠标位置缩放，停止约 180 毫秒后计算最终范围，点“返回概览”恢复整段。局部查看仅定位读取该段 WAV，使用更密集的时间帧，直接在界面绘制声谱矩阵与波形，省去中间 PNG 的保存和加载。每个查看窗口缓存最多 16 MiB 音频及 64 MiB 选区结果，重复查看相同选区时复用；WAV 更新后重新读取，关闭窗口时清空缓存。计算期间的新请求只保留最终范围，较早的结果不会覆盖它。新生成的分析概览、合并图和分开图会记录对应音频，分开图仅使用已分离的分量 WAV；旧 PNG 或已丢失关联 WAV 的图片仍可静态查看。“打开概览 PNG 原图”仍查看最初的概览文件。

局部放大后可在上方波形或下方声谱内按住左键左右拖动，保持当前时间跨度浏览前后内容；拖动中立即平移现有数据，停顿或松开后读取新范围，自动限制在概览时间边界内。Shift+左键仍用于框选。
Ctrl+滚轮向前放大、向后缩小，缩放时尽量保持鼠标所指时刻的位置；缩小后的范围超过局部精算的 2 秒上限时，直接返回整段概览。

长录音使用连续分块、跨块去重、有限并行与增量输出；停止后可从断点继续。
任一图片开关改变后需重新开始，不能混用旧断点的图片结果。
每批分析会一次性整理全部模板的数值特征、类别容差和频率轨迹，供所有文件和音频块复用；模板快照仍是原来的 JSON 格式。DTW 内部循环使用 Numba 编译加速，保留原有时间伸缩范围、同分顺序和相似度公式。首次调用存在编译开销，后续可复用工作区内的编译缓存。
对同一分量音频，建表特征和模板描述共享一次 STFT、超声功率谱、每帧峰值及未平滑主频；建表与模板各自保留原有的筛帧、平滑和频率轨迹处理规则，返回独立的特征字典。普通分量同时提取建表特征和模板轨迹时，特征阶段的 STFT 从三次减为一次；模板单独提取时从两次减为一次。检测、边界精修、分离及绘图使用的其他频谱参数不变。
新门控也复用该频谱，并接收分离阶段的已观测轨迹和分离前谱支持度，避免窄带掩膜把宽带噪声变成虚假的清晰叫声；不为门控另做 STFT。背景使用前后各 4ms 原混合音频的 RMS 和同频正弦投影。
本次处理格式更新后，旧版未完成断点需重新开始；已输出的文件保留。
统计单位是声学 call，不代表蝙蝠个体数量。

结果在 `results/segment_analysis/<run_id>/`：

- `pulse_predictions.csv`：逐 pulse 门控状态、通过路径（`band`/`rescue`/`template`）、三类分数、全带与局部带集中度、`gate_fail_*` 未达标项、`gate_promoted` 放行标记、原因、模板辅助结果及音频/图片路径。
- `segment_summary.csv`、`overall_species_summary.csv`：片段及类别统计。`gate_uncertain_count` 为门控待定；`template_promoted_count` 为其中按模板放行的条数（已计入有效叫声）；`template_unknown_count` 为 bat 中的模板 unknown，旧字段 `uncertain_count` 保留为后者的别名。有效叫声只统计 bat，三类门控计数之和等于可建表分量数。`max_subband_contrast_db` / `subband_only_candidates` 只在开启检测诊断时有值。
- `detection_diagnostics.csv`：可选的逐块诊断（默认关闭），记录全带与各子带的背景、对比度、阈值和候选数，用于解释"这个文件为什么没有候选"。列说明见 [检测诊断说明](docs/detection_diagnostics.md)。
- `template_model.json`、`run_metadata.json`：模板快照和运行参数。
- `segments/`、`separated/`、`figures/`、`pulse_spectrograms/`：音频、概览和逐声波图片。

## 源码与打包

- `app/`：桌面界面、后台任务与图片查看器。
- `segment_analysis.py`、`segment_stream.py`：分析、统计、流式运行与断点。
- `template_matching.py`：可信文件名类别解析与模板匹配。
- `morphology_gate.py`：三类形态评分、背景证据和 bat/noise/uncertain 门控。
- `boundary_reliability.py`、`sequence_analysis.py`：原音频边界证据、可靠参考筛选及连串判族。
- `audio_io.py`、`detection.py`、`pulse_table.py`、`features.py`、`separation.py`、`harmonics.py`：共享声波处理。
- `pulse_export.py`、`visualization.py`、`son_reader.py`：导出与查看。

`build_exe.bat` 使用 `bat_app.spec` 打包。修改源码后重启源码版程序生效；已有 EXE 需重新打包。
科学计算依赖仍需保留；librosa 可能间接安装 scikit-learn/joblib，不能因删除训练功能就强行卸载。
